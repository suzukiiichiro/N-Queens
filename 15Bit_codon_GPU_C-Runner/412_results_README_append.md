### 読み

- A1040 の壁が 402-r2 の +3.6% から +9.4% に高くなった。402-r2 以降ループが 140→108 命令になりメモリ側のストールの比率が
  相対的に上がったためと読める（命令が減るほど L1 あふれの罰則は目立つ）。律速の仮定込み。
- A1040 だけクロックが 1680 まで落ちた。温度は 64〜69 ℃で他セルと同じ、**電力が 298〜300 W（A10G の上限 300 W）**に
  張りついていたので熱絞りではなく電力絞り。13 ブロック/SM は L1 ミスで電力も食う。正規化後も +9.4% なので結論は動かない。
- B64_480 の +0.37% は 1 ブロック 2 ワープにしたぶんブロック単位の退出・補充の粒度が粗くなる方向（同じスレッド数、
  同じ作業集合）。0.37% は分解能（0.1%）の 3 倍以上で本物。
- ハーネスの小さな癖：`clk_*.tsv` の「busy のみ」フィルタ（util>50）はカーネル終了直後の数標本（電力が落ちていく区間）も
  拾う。全セル同じ扱いなので比較には影響しないが、次のハーネスでは power ≥ 200 W も条件に足す。
