### 地形の読み方

704〜968は**幅広い高原**(生で−19〜−27%)で、その上に**±4%のギザギザ**が
乗っている(800→864で+8.1%悪化、864→928で改善、968で再悪化)。滑らかな
L1圧曲線ではない。原因候補:

- **SMへのブロック配分の均一性**: 80 SMなら800 = ちょうど10ブロック/SM
  (完全均一)、864 = 64 SMが11・16 SMが10、928 = 48×12+32×11、968 =
  8×13+72×12。均一な点が有利で、最重SMが時間を決める。80の倍数
  (720/880/960)が系統的に良ければこの仮説が立つ。
- **stride固有のタスク配分**: warp内の32件グループはstrideによらず
  同一(394e)だが、per-thread列とSM別の負荷はstrideごとに変わり、
  394eではその成分が3〜7ptあった。L3の効果が点によって0〜−5%動くのも
  同じ成分(L3は隣接を99.4%保つが、クラス間移動でper-thread列が変わる)。

いずれも「800が真の最適点」ではなく「800が**サンプルした中で最良**」と
いう位置づけを変えない。**800は最良の実測点として採用する**が、隣接点
(784/816)と80の倍数(720/880/960)の追試は残課題(395系と並行可)。

### 968の再現性について

968生は5回で160,528〜163,197(幅1.6%)。484の±0.003%と比べて明らかに
広く、L1の崖の縁で配置感度が高い(394c)ことと整合する。800は1回しか
測っていないので、395aのK0で再現を見る。
