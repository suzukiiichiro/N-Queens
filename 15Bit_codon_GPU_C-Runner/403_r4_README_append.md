## 403-r4 — 本番 `-g` 経路でN≥22のヘルパーを外す（`.py` のみ、バイナリは403_r2dのまま）

### 403-r3で確定したこと（2026-09-29）— 採用なし

N=22の直接実行7走行、全オラクル一致・1710 MHz・居残りゼロ。

- **Q1 成立**：N=22でも960が鋭い最小（N=21と同じ形。フレーム／L1の機構はSM単位）。
- **Q2 反証**：N=22ではヘルパー（他プロセスctx）は効かない。|N960−H960| < 0.5%、符号は
  800／960／1040で揃わず、すべて±0.2%内。ディスパッチャ経由（free_mb 20,665）と直接
  （21,176／21,559）も+0.08%以内。**N=22はctx／メモリ状態にほぼ鈍感**で、N=21の−2%級の
  段差はN=22には存在しない。
- **Q3**：N=22のノイズフロア 0.003%。
- 唯一の残り物：960でヘルパーを外すと **−0.125%（約1.2秒）**。1組の比較だが再現ノイズの40倍。

### 403-r4の分割

コード変更はホスト側 `.py` の1点のみ。`.cu` は403_r3（＝403_r2d）の純粋リネーム（コード領域
バイト一致、kernel sha `14cba3d9`）。バイナリは `NQ_HELPER_CTX=0` を既に理解する（402-r4：
何もforkせず `[gpu-helper] helpers=0`）。

`.py` の実行行差分は403_r3Py比 **removed=4 added=10**：

```
VERSION_TAG / REV_TAG / テーブル行（バイナリ名のみ。env_prefix 文字列は不変）
A10G_FINAL_HELPER_MAX_N:int=21                       # 新定数
def crunner_env_prefix_for_n(base_env_prefix,N):     # 新関数（4行）
  N<=21 → そのまま
  N>21  → "NQ_HELPER_CTX=1 " を "NQ_HELPER_CTX=0 " に置換
mode-37（素の -g）のディスパッチ地点でこの関数を通す（1行）
```

- テーブル行の `env_prefix` は **N=21の本番文字列そのまま**（402-r5／403-r2dがディスパッチした
  ものとバイト一致）。N依存はこの関数の中だけに置く。`NQ_HELPER_MB=128` は残るがヘルパー0なら
  不活性で、403-r3のNセル「0/128」と同じ状態。`NQ_EXTRA_CTX=1`（9/9以降不活性）は素通し。
- `bench_mode=39`（並べ替え済み入力のディスパッチ）は触らない（静的ゲートで呼び出し箇所を
  def＋1サイトの2箇所に固定）。
- 処遇を env_prefix 側（コマンド行のトークン）に置くのは395c-r6／402-r5と同じ理由：`dispatch.log`
  の `[crunner-config] env_prefix=` に記録が残る。N=22の行には `NQ_HELPER_CTX=0` が残る。
- **N=21側は「同一バイナリ・同一SASS・同一env」**なので性能上の変化点は無い。これをV1（SASS）と
  V2（dispatch.log の文字列一致＋G21）で担保する。

### 事前登録予測（実測前に固定）

1. **V1（ハード）**：`.cu` コード領域が403_r3／403_r2dと一致、`<402>` のSASSが402_r5と、
   `<403>` が403と完全一致。落ちればGPUを回さない。
2. **V2（ハード）**：G21 オラクル一致・`layout=402`・`helpers=1`、`dispatch.log` のN=21
   `env_prefix` が403-r2dと**同一文字列**（`NQ_MAX_BLOCKS=960 NQ_EXTRA_CTX=1 NQ_HELPER_CTX=1
   NQ_HELPER_MB=128`）、G21 が 109,437 の ±0.15%。**表明**：109,460（r2d G21）の ±0.05%。
   V2が落ちればN=22を回さず停止（N=21側が動いたことになる）。
3. **V3（ハード）**：G22a／G22b オラクル 2,691,008,701,644・`layout=403`・`helpers=0`、
   `dispatch.log` のN=22 `env_prefix` に `NQ_HELPER_CTX=0`。
4. **V4（表明）**：mean(G22a, G22b) ≤ アンカー −0.08%（期待は約−0.125%）。**反証**：|差| ≤ 0.04%
   （直接実行で見た差はディスパッチャ経路には移らない）。間はグレーで採用しない。G22が遅ければ
   別ラベルで落とす。
5. **V5（情報）**：|G22a−G22b| ≤ 0.02%（N=22のフロアは0.003%）。
6. **V6**：全セル 1710±2%。

**採用則**：V1〜V3ハード通過・V4成立・V5 ≤ 0.05% で `403_r4Py` を本番 `.py` にする。本番値は
N=21 不変（109,4xx）、**N=22 986,6xx ms**。V4反証またはG22が遅ければ採用せず、`403_r2d`／
`403_r3` Py のまま（N=22でヘルパーは無害で、その方が単純）。採用時はREADME本文のN=22本番値と
「ヘルパーはN≤21のみ」を更新する。
