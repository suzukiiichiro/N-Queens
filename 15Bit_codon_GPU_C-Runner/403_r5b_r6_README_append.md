- **P1・P2ともグレー**（表明 ≤0.985／反証 ≥0.997 の間）。事前登録の採用則では採用なし。
- 効果は本物（N=22フロアの150倍、N=21／22で同符号・同程度、結果バイト一致）だが、大きさは

  最長の鎖になった。402のldは1段、旧403は2段。

### 403-r6 — popのldを1命令に畳む綴り探索（GPU時間ゼロ）

403_r5の `.cu` からpopの1行だけを差し替えた7変種をビルドし、各変種について `<402>` SASSが402_r5と
一致すること（`if constexpr` の403分岐内なので必ず成立）、`<403>` の命令数、pop領域（LDL〜ループ
戻り）の命令列を出す。実行はしない。

| 変種 | 綴り |
|---|---|
| v0 | r5のまま `((uint32_t)(packed_a >> 43) & ~1u) \| (packed_b & 1u)` |
| v1 | XOR選択 `a43 ^ ((a43 ^ packed_b) & 1u)` |
| v2 | 定数マスク明示 `& 0xfffffffeu` |
| v3 | 戻しシフト `((uint32_t)(packed_a >> 44) << 1) \| (packed_b & 1u)` |
| v4 | 64ビットで選択してから切り詰め |
| v5 | インラインPTX `lop3.b32 %0, a43, packed_b, 1, 0xD8`（CPU側は v0 と同じCにフォールバック） |
| v6 | マスクを変数に `m = 1u; (a43 & ~m) \| (packed_b & m)` |

7変種とも意味は同一（2×10⁷回のランダム比較で v0 と全一致を確認済み）、gccビルド済み。
目標は **SHF＋LOP3の2段**（ldの深さ2＝`avail` と同じ）で命令数 ≤496。それが出た変種を403-r6
（GPU走行あり：Z／X／G22の再測）にする。どの変種でも3段のままなら、ptxasは折らないと記録し、
`<403>` と `<402>` の命令並び差の読みに進む。

```
bash 403_r6_compile_search.sh   # 約5分。403_r6_search_<ts>.tar.gz を送付
```
