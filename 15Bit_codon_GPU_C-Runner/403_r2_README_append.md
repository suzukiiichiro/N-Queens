## 403-r2 — 1バイナリでN≤22（12バイトフレームの2レイアウトをNで選択）

### 403で確定したこと（2026-09-28）

ハードゲート W1〜W4 全通過（ptxas 160 B／40レジスタ、CPU等価 N=21 8,192件・N=22 16,384件、
N=23 rc=3、N=21フル入力スレッド別バイト一致）。`-g 22 22`（960・ヘルパー1＋128 MB）＝
**987,065 ms（16:27）**、オラクル一致、free_mb 20,665、k=935。9/9の1,140,988比 −13.5%
（W7の≤969,840には届かず中間域）。

**W5は反証**：E0（402_r5）109,416 対 E1（403）112,464 ＝ **+2.79%**。403レイアウトはldが
word A/Bに20+1で分かれ、pop直後の依存鎖が伸びる。393-8「命令を足すと負ける」は命令数
（402で−3%）ではなく、**pop直後の依存鎖を伸ばす命令**については正しかった。

結果、ヘッドはバイナリ2本（N=21＝402_r5、N=22＝403）・テーブル2行になっている。

### 403-r2の分割

`process_one_task` に `const int layout` を足し、スタックの3サイト（push 2・pop 1）を
`if (layout == 402) {402の文} else {403の文}` にする。`__global__` カーネルは
`template <int LAYOUT>` で402/403の2実体、`process_one_task` は強制インライン（402／403でも
nvccは既にインライン化しており、ptxasのエントリは1つ）。各実体では `layout` が定数に畳まれ、
**実行時分岐は残らない**（はず——Y1・Y5で検証）。ホストは N≤21→402、N=22→403 を選び
（`NQ_LAYOUT=402|403|auto` で上書き可。402でN=22はrc=3、N>22はrc=3）、
`[gpu-layout] N=.. requested=.. layout=..` をログに出して当該実体を起動する。
`cudaFuncSetAttribute`／`GetAttributes` も選んだ実体を指す。CPUハーネスも同じ選択を行い
（`[cpu-layout]`）、算術は一切変えていない。

**402の文は402 READMEの記述（A = ld[0..20] | col<<21 | avail<<42、B = rd）から再構成した**
もので、402_r5のソースは手元にない。そこでハーネスの静的ゲート Y0 が
`402_r5_kernel_maxd14.cu` からpush/pop 6文を抜き出し、空白正規化で403-r2に文字一致で
存在することを要求する（不一致ならMISSINGを表示して停止。`ALLOW_402_TEXT_MISMATCH=1` で
CPU/GPU等価ゲートだけで進める道も残す）。**初回実行でY0が1文を検出**：402_r5のpopは
`cur_rd = stack_b[stack_ptr];` と直接読んでおり（`packed_b` ローカルなし）、403-r2の402分岐も
同じ文にし、`packed_b` は403分岐の中だけに置いた。6/6一致。

**手元検証**：合成 N=21／N=22 各4,000レコード（ldの盤外ビットとrd bit 0にゴミ入り）で、
402分岐・403分岐・403本体がN=21でバイト一致、autoがN=22で403と一致。NQ_LAYOUT=402@N=22、
NQ_LAYOUT=bad、N=23 はいずれもrc=3。スタブヘッダでの `g++ -fsyntax-only` によりテンプレート
2実体・`cudaFuncSetAttribute(kernel<402>, …)` の構文を確認（nvccは手元にない）。
コード領域差分 removed=25 added=99（コメント除去後）、カーネル領域sha 変更。
**ハーネス修正**：.cuの差分・sha指紋は**Cコメント（`/* */`・`//`）と空行を除いたコード領域**で
取るようにした。403までのハーネスは.cu側でコメント行も数えており、手で追記したノートで指紋が
動いていた（恒久ルール違反）。コメントを40行足しても指紋が動かないことを手元で確認。

### `*_README_append.md` との照合

402（3×21ビット、depthをレジスタへ）、403（死にビット2つでN≤22、N=21で+2.79%）、
393-8（但し書き：依存鎖）。「レイアウトをNで切り替えて1バイナリに戻す」案は
**該当なし**（403の引継ぎメモ「明日の候補1」が初出）。
