### 教訓（恒久ルールへ）

26. **CUDA を呼ぶ工程に `ulimit -v` を掛けない**（367 ラッパー）。CUDA 初期化の仮想アドレス予約で即 Segfault する。守るなら RSS 側で。
27. **長い走行は電力上限（300 W）で定常的に 1680〜1695 MHz になる。** N=23 の本番値はこの状態の値。別セッションの N=23 と比べるときは norm_ms。
28. L1 の論理（フレーム×常駐スレッド ≤ 64 KB）は MB の最小の位置を説明するが、176 B×12 ブロック＝67.6 KB で L1 をはみ出しても 960 が 880 に 5.7% 勝つ。
    「L1 ちょうど」より「12 ブロック/SM」の方が優先する（律速の仮定：ワープ数で隠すレイテンシ ＞ L1 ヒット率）。N=24 以降の MB も 960 から始めて掃引する。
29. 部分入力の等間隔スライスは全件の絶対時間を ±6%（今回）〜±37%（398-r2）で外す。フル実行の見込み時間を出すには使うが、本番値はフル実行のみ。
30. N=23 の入力構築は 10 分以内（361 ダンプ 1.5 分、メモ化フィルタ数分、sched 数分）。初回の見込み 40〜60 分は過大だった。
    フィルタのメモ化は (ctrl0, markctrl) の種類が少ない（1,350）ことに依存する。
