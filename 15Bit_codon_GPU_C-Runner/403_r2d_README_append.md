## 403-r2d — フロントエンドに402_r5を見せる綴り（`template` ＋ `if constexpr`）

### 403-r2cで確定したこと（2026-09-29、コンパイルのみ）

- **C0 成立**：402_r5をソースから再ビルドすると既存バイナリとSASS完全一致（496命令）。nvccは決定的。
- **R2 反証**：8変種すべて——`__forceinline__` なし、明示実体化の両順序、素のカーネル2つ（402側は
  402_r5と同じマングル名）、**第2カーネルの無い `<402>` 単実体**まで——が**同じ63命令差**
  （`<403>` 側も同じ40命令差）。テンプレートでも、インラインでも、第2カーネルの存在でもない。
- **P1**：PTXの段階で既に69行違う（ループ持ち越し値 cur_ld/rd/col/avail/depth の `mov` の順序と、
  popの `ld.local` の位置）。フロントエンド（NVVM）が「3サイトに `if (layout == 402)` がある関数」から
  SSAを作り、後で定数畳み込みをしても、402_r5の分岐なし関数とは値番号・PHI順が違う。ptxasの同点
  判定はその上で変わる。

結論：**畳まれる実行時分岐は「分岐なし」と同じ入力ではない**。分岐を消すには、フロントエンドが
分岐を見ない綴りが要る。

### 403-r2dの分割

`process_one_task` を `template <int layout>`（C++/CUDA）にし、スタック3サイトを
`LAYOUT_IF(...)` ＝ `if constexpr` にする。捨てられる側は実体化されないので、`<402>` の本体は
402_r5の文そのもの（余分な複文スコープ `{ }` のみ）。CPUハーネス（`gcc -x c`）にはテンプレートも
`if constexpr` も無いので、そちらは403-r2と同じ「実行時 `int` ＋素の `if`」——4つのマクロ
（`POT_TEMPLATE`／`POT_LAYOUT_PARAM`／`POT_TARGS`／`POT_LAYOUT_ARG`／`LAYOUT_IF`）で切り替える。
`__global__` カーネルは `process_one_task<LAYOUT>` を呼ぶ。算術は不変。

**手元検証**：合成N=21／N=22各4,000件（死にビットにゴミ入り）で402分岐・403分岐・403本体がバイト
一致。`g++ -std=c++17 -fsyntax-only`（スタブCUDAヘッダ）でテンプレート／`if constexpr` の構文を
確認。コード領域差分（コメント除去後）403_r2比 removed=9 added=23。nvccは手元にないので、
**SASS一致はハーネスのS2がハードゲートとして判定し、落ちればGPUは一切回さない**。

### `*_README_append.md` との照合

403-r2（テンプレート化）、403-r2b／r2c（SASS・PTX比較）。`if constexpr` による実体化の分離は
**該当なし**。

### セルと事前登録予測（実測前に固定）

セルは403-r2と同じ：X0（402_r5）／X1（403_r2d auto）／X3（403_r2d `NQ_LAYOUT=403`）／G21／G22。

5. **Y5'（表明）**：|X1 − X0| ≤ 0.05%（SASS同一 → ノイズフロア0.04%の内側）。0.05〜0.15%はグレー
   （再測定）、**>0.15%は反証**（SASS同一でも時間が違う → コードではなく状態の別問題）。
6. **Y6'（表明）**：X3／X0 が [1.025, 1.031]（403の+2.79%を、403そのもののSASSで再現）。
7. **Y7（ハード）**：G21 オラクル一致・`layout=402`。表明：109,437の±0.15%。
8. **Y8（ハード）**：G22 オラクル一致・`layout=403`。表明：987,065の±0.5%（S3成立なら403のSASSなので
   403の値に戻るはず。403-r2の並べ替え版は983,926だった——S3不成立ならそちらを基準に読む）。
9. **Y9**：全セル1710±2%。

**採用則**：S0〜S2・Y2〜Y5'・Y7 がすべて成立 → 403_r2dが本番テーブル行。ヘッドは1バイナリ・1行で
N≤22、本番 N=21 109,4xx／N=22 987,0xx（S3次第で983,9xx）。

所要：静的＋ビルド＋SASS約2分、Y2〜Y4＋X0/X1/X3 約8分、G21 約2分、G22 約17分 → **約27分**。
`SKIP22=1` で約10分。
