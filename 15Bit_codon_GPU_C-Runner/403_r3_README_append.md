ハードゲート全通過、全オラクル一致、1710 MHz。**403_r2dが本番**：1バイナリでN≤22、本番値
N=21 **109,4xx ms**、N=22 **987,079 ms**。

r2→r2b→r2c→r2dの教訓（恒久ルールに追加）：
- **性能の再現性はソースの文字一致ではなく、SASSの一致で担保する**。同一SASSなら時間差は0.002%。
- **畳まれる実行時分岐は、フロントエンドにとって「分岐なし」と同じ入力ではない**（PTXの値番号・
  PHI順が変わり、ptxasの同点判定が変わる）。`if constexpr` なら同じになる。
- 並べ替えは損にも得にもなる（403_r2の `<402>` は+0.12%、`<403>` は−0.3%）。

### 事前登録予測（実測前に固定）

- **Q1（表明）**：ヘルパー梯子で960が最小、800・1040とも **≥ +2%**（フレーム／L1の機構はSM単位で
  Nに依らない。N=21では両隣+4%）。**反証**：どちらかの隣が < +1%。+1〜2%はグレー。
- **Q2（表明）**：960でのヘルパー効果あり：N960 − H960 が **[+1%, +3%]**（N=21：+2.26%）。
  **反証**：|N960 − H960| < 0.5%（N=22のメモリ状態はN=21の切り欠きの外なので、効かない可能性を
  対立仮説として明記）。
- **Q3（情報）**：N=22の再現 |H960r − H960|。≤ 0.1% と予想（N=21のフロアは0.04%）。
- **Q4（ハード）**：全セルオラクル一致、`layout=403`。**Q5**：全セル1710±2%。
- アンカー：H960 が 987,079 の ±0.2%（外れても梯子はH960基準で読む）。

**本リビジョンで採用するものは無い。** H960を1%超上回るセルがあれば、403-r3bで再現してから
