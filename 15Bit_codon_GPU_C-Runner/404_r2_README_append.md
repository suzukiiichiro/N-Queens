### 404-r2の変更

`select_pack_layout()` の実行行1行：`NQ_LAYOUT=auto`（既定）が、従来は N≤21→402／N=22→403 だったのを、
**全Nで403**にする。`NQ_LAYOUT=402` でN≤21は402レイアウトのまま走れる（N=22は従来どおり拒否）。
`process_one_task()` とカーネル2実体は不変なので、`<402>` `<403>` のSASSは404と同一。
CPUハーネスも同じ関数を使うので、`auto` は403になる。

- `.cu`：404比 コード領域 **removed=1 added=1**。
- `.py`：404Py（本番）の純粋リネーム、実行行3行。
- ハーネス：`404_r2_validate.sh`。診断バイナリd5（404＋C）は、ハーネスが404の `.cu` に生成器（C）を適用して作り、
  shaを探索結果と照合する。
